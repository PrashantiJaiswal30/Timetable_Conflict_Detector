# Project Statement

## Project Title

Timetable Conflict Detector

## Problem Statement

Creating and managing class timetables manually can result in overlapping classes and scheduling conflicts. These conflicts may occur when two classes are scheduled at the same time on the same day.

The Timetable Conflict Detector is developed to identify such overlapping timetable entries and help users detect scheduling conflicts.

## Aim

The aim of this project is to develop a simple Python program that can detect conflicts between classes in a timetable.

## Objectives

1. To store timetable information.
2. To accept class details from the user.
3. To compare class timings.
4. To identify overlapping classes on the same day.
5. To display the detected conflicts clearly.
6. To demonstrate the use of Python programming concepts.

## Scope

The project can be used to check a basic academic timetable for overlapping class timings.

The system can store:

- Day
- Subject
- Start time
- End time
- Room number
- Teacher name

## Python Concepts Used

The project demonstrates:

- Variables
- Lists
- Dictionaries
- Functions
- Loops
- Conditional statements
- String operations
- File handling

## Proposed Solution

The system accepts timetable details and compares the timings of different classes scheduled on the same day.

If the time periods overlap, the system reports the classes as a timetable conflict.

## Expected Outcome

The program should successfully identify overlapping classes and display the conflicts to the user in a clear format.

## Conclusion

The Timetable Conflict Detector provides a simple Python-based approach for identifying timetable conflicts and demonstrates practical use of basic programming concepts.
