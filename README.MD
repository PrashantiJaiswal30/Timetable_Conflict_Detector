# Timetable Conflict Detector

## Project Description

The Timetable Conflict Detector is a Python-based project designed to identify conflicts in a class timetable.

It checks whether two or more classes are scheduled on the same day with overlapping times.

## Objectives

- Store timetable information.
- Accept class details from the user.
- Check for overlapping class timings.
- Detect timetable conflicts.
- Display the timetable clearly.
- Display detected conflicts.

## Features

- Add multiple classes.
- Store subject, day, time, room, and teacher details.
- Detect overlapping timings.
- Display conflicts in an easy-to-understand format.
- Use Python lists, dictionaries, functions, loops, and file handling.

## Technologies Used

- Python
- Visual Studio Code
- Text File Handling

## Project Files

- `main.py` - Main program.
- `timetable.py` - Handles timetable information.
- `conflict_detector.py` - Detects timetable conflicts.
- `display.py` - Displays timetable and conflict results.
- `timetable_data.txt` - Stores timetable data.
- `STATEMENT.md` - Contains the project statement.

## How to Run

1. Open the project folder in Visual Studio Code.
2. Open `main.py`.
3. Click the Run button.
4. Enter the number of classes.
5. Enter the details of each class.
6. The program will display the timetable and any conflicts.

## Example

If two classes are scheduled as:

- Maths: Monday, 09:00 - 10:00
- Physics: Monday, 09:30 - 10:30

The program detects that their timings overlap and reports a conflict.

## Conclusion

The project provides a simple way to identify overlapping classes in a timetable using Python.
